階段二：模型架構定義

1. 3D U-Net 基礎模組

DoubleConv3D 類別：

包含兩次 3D 卷積、批次正規化 (BatchNorm3d) 和 ReLU 激活函數，是 U-Net 的基本建構單元。


class DoubleConv3D(nn.Module):
    """
    定義 3D 卷積層組合，包含兩次卷積、BatchNorm 與 ReLU 激活函數。
    此結構常用於 U-Net 中作為基本模組。
    """
    def __init__(self, in_channels: int, out_channels: int):
        super().__init__()
        self.conv = nn.Sequential(
            # 第一次卷積
            nn.Conv3d(in_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm3d(out_channels),
            nn.ReLU(inplace=True),
            # 第二次卷積
            nn.Conv3d(out_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm3d(out_channels),
            nn.ReLU(inplace=True),
        )

    def forward(self, x):
        return self.conv(x)

2. 3D U-Net 模型

UNet3D 類別：

  • 編碼器 (Encoder)：多層 DoubleConv3D 和最大池化層 (MaxPool3d) 進行下採樣。
  • 瓶頸層 (Bottleneck)：位於編碼器和解碼器之間的 DoubleConv3D。
  • 時間嵌入整合：將時間步嵌入向量透過線性層投影後，與瓶頸層特徵相加。
  • 解碼器 (Decoder)：多層反卷積層 (ConvTranspose3d) 和 DoubleConv3D 進行上採樣，並與編碼器對應層的特徵進行拼接 (skip connections)。
  • 輸出卷積層：將特徵圖通道數降為 1。
  • 輸入處理：接收含噪聲的目標數據 x_t、完整的序列數據 x_full，並將 x_full 通過 1x1 卷積後與 x_t 融合。

class UNet3D(nn.Module):
    """
    3D U-Net 結構，包含下採樣（Encoder）、中間瓶頸層與上採樣（Decoder）。
    此模型同時接收噪聲版本的目標數據 x_t、完整序列 x_full 與時間嵌入。
    """
    def __init__(self, in_channels=1, base_channels=64, time_emb_dim=128, dropout_rate=0.0):
        super().__init__()
        # 編碼器部分：逐層進行雙卷積與下採樣
        self.enc1 = DoubleConv3D(in_channels, base_channels)
        self.pool1 = nn.MaxPool3d((2, 2, 2))
        self.enc2 = DoubleConv3D(base_channels, base_channels * 2)
        self.pool2 = nn.MaxPool3d((2, 2, 2))
        self.enc3 = DoubleConv3D(base_channels * 2, base_channels * 4)
        self.pool3 = nn.MaxPool3d((2, 2, 2))
        self.enc4 = DoubleConv3D(base_channels * 4, base_channels * 8)
        # 這裡使用不同的池化參數以調整深度與空間尺寸
        self.pool4 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(1, 2, 2), padding=(1, 0, 0))
        # 瓶頸層
        self.bottleneck = DoubleConv3D(base_channels * 8, base_channels * 16)
        # 解碼器部分：逐層上採樣並與對應編碼層做 concat
        self.up4 = nn.ConvTranspose3d(base_channels * 16, base_channels * 8, kernel_size=(2, 2, 2), stride=(1, 2, 2), output_padding=(0, 1, 1))
        self.dec4 = DoubleConv3D(base_channels * 16, base_channels * 8)
        self.up3 = nn.ConvTranspose3d(base_channels * 8, base_channels * 4, kernel_size=(2, 2, 2), stride=(2, 2, 2), output_padding=(1, 0, 0))
        self.dec3 = DoubleConv3D(base_channels * 8, base_channels * 4)
        self.up2 = nn.ConvTranspose3d(base_channels * 4, base_channels * 2, kernel_size=(2, 2, 2), stride=(2, 2, 2))
        self.dec2 = DoubleConv3D(base_channels * 4, base_channels * 2)
        self.up1 = nn.ConvTranspose3d(base_channels * 2, base_channels, kernel_size=(2, 2, 2), stride=(2, 2, 2))
        self.dec1 = DoubleConv3D(base_channels * 2, base_channels)
        # 輸出卷積，將通道數降為 1
        self.out_conv = nn.Conv3d(base_channels, 1, kernel_size=1)
        # dropout 用於防止過擬合
        self.dropout = nn.Dropout3d(dropout_rate)
        # 時間嵌入的線性轉換與激活
        self.time_proj = nn.Sequential(nn.Linear(time_emb_dim, base_channels * 8), nn.SiLU())
        # 將完整序列 x_full 通過 1x1 卷積調整通道數，使其與 x_t 保持一致（這裡假設保持 1 通道）
        self.x_full_conv = nn.Conv3d(in_channels, in_channels, kernel_size=1)

    def forward(self, x_t, x_full, t_emb):
        """
        前向傳播函數：
        參數:
            x_t: 含噪聲的部分序列，形狀 (batch, 1, 9, 21, 21)
            x_full: 完整的序列數據，形狀 (batch, 1, 9, 21, 21)
            t_emb: 時間嵌入，形狀 (batch, time_emb_dim)
        回傳:
            模型輸出，形狀 (batch, 1, 1, 21, 21)
        """
        # 處理 x_full，使其通道數與 x_t 一致
        x_full_conv = self.x_full_conv(x_full)  # (batch, 1, 9, 21, 21)
        # 將 x_t 與處理後的 x_full 做融合（逐元素相加）
        x_input = x_t + x_full_conv  # (batch, 1, 9, 21, 21)
        # 編碼器第一層
        e1 = self.enc1(x_input)  # (batch, 64, 9, 21, 21)
        e2 = self.enc2(self.pool1(e1))
        e3 = self.enc3(self.pool2(e2))
        e4 = self.enc4(self.pool3(e3))
        p4 = self.pool4(e4)
        # 將時間嵌入經線性轉換後擴展至與 p4 同維度並與 p4 相加
        t_emb = self.time_proj(t_emb)[:, :, None, None, None]
        b = self.bottleneck(p4 + t_emb)
        b = self.dropout(b)
        # 解碼器：上採樣後與對應編碼層做 concat
        d4 = self.up4(b)
        if d4.shape[-3:] != e4.shape[-3:]:
            # 使用 trilinear 插值調整尺寸
            d4 = F.interpolate(d4, size=e4.shape[-3:], mode='trilinear', align_corners=True)
        d4 = self.dec4(torch.cat([d4, e4], dim=1))
        d3 = self.up3(d4)
        if d3.shape[-3:] != e3.shape[-3:]:
            d3 = F.interpolate(d3, size=e3.shape[-3:], mode='trilinear', align_corners=True)
        d3 = self.dec3(torch.cat([d3, e3], dim=1))
        d2 = self.up2(d3)
        if d2.shape[-3:] != e2.shape[-3:]:
            d2 = F.interpolate(d2, size=e2.shape[-3:], mode='trilinear', align_corners=True)
        d2 = self.dec2(torch.cat([d2, e2], dim=1))
        d1 = self.up1(d2)
        if d1.shape[-3:] != e1.shape[-3:]:
            d1 = F.interpolate(d1, size=e1.shape[-3:], mode='trilinear', align_corners=True)
        d1 = self.dec1(torch.cat([d1, e1], dim=1))
        # 經過輸出卷積獲得最終結果
        out = self.out_conv(d1)
        # 返回結果，僅保留時間維度上的第一個步驟（1個預測步長）
        return out[:, :, :1, :, :]

3. DDPM (Denoising Diffusion Probabilistic Model)

DDPM3D 類別：

  • 初始化：設定時間步長 (timesteps)、beta 排程 (線性)、計算 alpha 及相關擴散係數。
  • 時間嵌入 (get_time_embedding)：將標量時間步轉換為固定維度的向量表示 (使用正弦和餘弦函數)。
  • 條件嵌入 (get_condition_embedding)：目前返回零向量，可擴展以整合額外條件。
  • 前向擴散過程 (q_sample)：根據時間步 t，將原始數據 x0 添加高斯噪聲。
  • 損失計算 (p_losses)：計算模型預測的噪聲與實際添加的噪聲之間的均方誤差。模型輸入為含噪聲序列 x_t、完整序列 x_full 及時間嵌入。
  • 單步反向去噪 (p_sample)：從含噪數據 x_t 預測並移除噪聲，得到 x_{t-1}。
  • 反向去噪迴圈 (p_sample_loop)：從純高斯噪聲開始，迭代執行 p_sample 直至 t=0，生成最終樣本。

class DDPM3D(nn.Module):
    """
    條件式 DDPM (Denoising Diffusion Probabilistic Model) 模型。
    此模型利用前向擴散與反向去噪過程進行生成任務。
    """
    def __init__(self, model: nn.Module, timesteps: int = 1000,
                 beta_start: float = 1e-4, beta_end: float = 0.02, device: str = 'cuda'):
        super().__init__()
        self.model = model
        self.timesteps = timesteps
        self.device = device
        # 線性生成 beta 值
        self.betas = torch.linspace(beta_start, beta_end, timesteps).to(device)
        self.alphas = 1.0 - self.betas
        # 累乘計算 alpha 的連乘積，用於生成擴散過程的係數
        self.alphas_cumprod = torch.cumprod(self.alphas, dim=0)
        self.sqrt_alphas_cumprod = torch.sqrt(self.alphas_cumprod)
        self.sqrt_one_minus_alphas_cumprod = torch.sqrt(1.0 - self.alphas_cumprod)
        # 計算頻率因子，用於時間嵌入的正弦與餘弦函數
        # TIME_EMB_DIM is a global constant, ensure it's defined if running this snippet standalone
        # For this example, assume TIME_EMB_DIM = 128
        TIME_EMB_DIM = 128 # Added for standalone context
        self.half_dim = TIME_EMB_DIM // 2
        self.freq_factor = torch.exp(torch.arange(self.half_dim, dtype=torch.float32) *
                                     -(math.log(10000.0) / (self.half_dim - 1))).to(device)

    def get_time_embedding(self, t):
        """
        生成時間嵌入向量，使用正弦與餘弦函數將標量時間映射到向量。
        參數:
            t: 時間步（batch_size,)
        回傳:
            時間嵌入，形狀 (batch_size, TIME_EMB_DIM)
        """
        t = t.float()
        emb = t[:, None] * self.freq_factor.to(t.device)
        return torch.cat([torch.sin(emb), torch.cos(emb)], dim=1)

    def get_condition_embedding(self, cond):
        """
        取得條件嵌入，目前未使用條件資訊，返回全零向量。
        """
        # TIME_EMB_DIM is a global constant
        TIME_EMB_DIM = 128 # Added for standalone context
        return torch.zeros(cond.shape[0], TIME_EMB_DIM, device=cond.device)

    def q_sample(self, x0, t, noise=None):
        """
        前向擴散過程：根據給定的時間步 t，將數據 x0 擴散成含噪版本。
        參數:
            x0: 原始數據
            t: 時間步（batch_size,)
            noise: 可選噪聲，若未提供則生成隨機噪聲
        回傳:
            擴散後的數據
        """
        if noise is None:
            noise = torch.randn_like(x0)
        # 根據時間步獲取相對應的係數
        sqrt_alpha = self.sqrt_alphas_cumprod[t].view(-1, 1, 1, 1, 1)
        sqrt_one_minus_alpha = self.sqrt_one_minus_alphas_cumprod[t].view(-1, 1, 1, 1, 1)
        # 混合原始數據與噪聲
        return sqrt_alpha * x0 + sqrt_one_minus_alpha * noise

    def p_losses(self, cond, target, t):
        """
        計算去噪損失，目標是讓模型預測出噪聲部分。
        參數:
            cond: 條件序列（含目標數據與前置條件）
            target: 真實目標數據
            t: 時間步
        回傳:
            均方誤差損失
        """
        # 構造完整無噪聲序列：將 target 與條件序列的後半部拼接
        x_full = torch.cat([target, cond[:, :, 1:]], dim=2)
        noise = torch.randn_like(target)
        # 生成含噪 target
        x_noisy_target = self.q_sample(target, t, noise=noise)
        # 將含噪 target 與條件序列拼接，作為模型輸入
        x_t = torch.cat([x_noisy_target, cond[:, :, 1:]], dim=2)
        # 取得時間嵌入與條件嵌入，並融合
        time_emb = self.get_time_embedding(t).to(self.device)
        cond_emb = self.get_condition_embedding(cond) # Assuming cond is just used for shape for zeros
        combined_emb = time_emb # + cond_emb # cond_emb is zeros, so effectively just time_emb

        # 預測噪聲
        pred_noise = self.model(x_t, x_full, combined_emb)
        pred_noise_target = pred_noise[:, :, :1, :, :]
        # 計算模型預測與實際噪聲間的均方誤差
        return F.mse_loss(pred_noise_target, noise)

    @torch.no_grad()
    def p_sample(self, x_t, t, cond):
        """
        單步反向去噪：從含噪數據 x_t 生成前一步的數據。
        參數:
            x_t: 當前含噪數據，形狀 (batch, 1, 1, H, W) 或 (batch, 1, 9, 21, 21)
            t: 當前時間步
            cond: 條件數據
        回傳:
            去噪後的數據 x_{t-1}
        """
        # 確保 x_t 與 cond 為 5 維張量
        if x_t.dim() == 4:
            x_t = x_t.unsqueeze(1)  # (batch, 1, 1, H, W)
        if cond.dim() == 4: # Assuming cond is (batch, 9, 21, 21) initially
            cond = cond.unsqueeze(1)  # (batch, 1, 9, 21, 21)

        # 取得當前時間步的 beta 等係數
        beta_t = self.betas[t].view(-1, 1, 1, 1, 1)
        sqrt_recip_alpha_t = 1.0 / torch.sqrt(self.alphas[t]).view(-1, 1, 1, 1, 1)
        sqrt_one_minus_alphas_cumprod_t = self.sqrt_one_minus_alphas_cumprod[t].view(-1, 1, 1, 1, 1)
        time_emb = self.get_time_embedding(t).to(self.device)
        cond_emb = self.get_condition_embedding(cond) # Assuming cond is (batch, 1, 9, 21, 21)
        combined_emb = time_emb # + cond_emb # cond_emb is zeros

        # 將含噪數據與條件數據合併
        # x_t is (batch, 1, 1, H, W), cond is (batch, 1, 9, H, W)
        # We need to construct the input for the model which expects (batch, 1, 9, H, W)
        # The first slice of the time dimension of the input should be x_t (the noisy target)
        # The remaining 8 slices should be the actual condition from cond
        x_t_full = torch.cat([x_t, cond[:, :, :8, :, :]], dim=2)  # (batch_size, 1, 9, 21, 21)
        x_full = cond  # 完整序列作為條件

        # 模型預測噪聲
        eps_theta = self.model(x_t_full, x_full, combined_emb)
        eps_theta_target = eps_theta[:, :, :1, :, :]  # 僅取出目標噪聲部分

        # 反向去噪步驟：計算 x_{t-1}
        x_t_minus_1 = sqrt_recip_alpha_t * (x_t - beta_t / sqrt_one_minus_alphas_cumprod_t * eps_theta_target)
        # 當 t > 0 時，加入隨機噪聲；t = 0 時直接返回
        mask = (t > 0).float().view(-1, 1, 1, 1, 1)
        sigma_t = torch.sqrt(beta_t)
        noise = torch.randn_like(x_t) # Noise should be like x_t, which is (B, 1, 1, H, W)
        return x_t_minus_1 + mask * sigma_t * noise

    @torch.no_grad()
    def p_sample_loop(self, shape, cond):
        """
        反向去噪迴圈：從初始純噪聲開始，逐步去噪生成數據。
        參數:
            shape: 生成數據的形狀（通常是目標的形狀, e.g., (batch, 1, 1, H, W)）
            cond: 條件數據 (e.g., (batch, 1, 9, H, W))
        回傳:
            生成的數據張量
        """
        # 確保 cond 為 5D
        if cond.dim() == 4:
            cond = cond.unsqueeze(1)  # (batch, 1, 9, 21, 21)

        # 調整 shape 為 5D if it's 4D (B, C, H, W) -> (B, 1, C, H, W)
        # For this model, shape is expected to be (B, 1, 1, H, W) for the target
        if len(shape) == 4: # e.g. (batch_size, 1, H, W) for target
             # This implies the target is single channel, single time step
             # The output of p_sample is (B, 1, 1, H, W)
             # So initial noise x should also be (B, 1, 1, H, W)
             shape = (shape[0], shape[1], 1, shape[2], shape[3]) # (B, C, 1, H, W)
                                                                 # (B, 1, 1, H, W) for this case


        # 初始噪聲, shape should represent the noisy target x_t, typically (B, 1, 1, H, W)
        x = torch.randn(shape, device=self.device)


        # 由最後一步開始，逐步進行去噪
        for i in reversed(range(self.timesteps)):
            t_scalar = torch.full((shape[0],), i, device=self.device, dtype=torch.long)
            x = self.p_sample(x, t_scalar, cond) # x is (B, 1, 1, H, W)

        return x

階段三：基礎 DDPM 模型訓練

1. 資料集分割與載入器準備

將 PeopleFlowDatasetCondition 實例分割為訓練集、驗證集和測試集。

為每個子集創建 DataLoader。

2. 初始化基礎模型

實例化 UNet3D 作為噪聲預測網路。

實例化 DDPM3D (diffusion model)，將 UNet 傳入。

若有預訓練權重，則載入。(筆記本中載入了 `best_model.pth`)

3. 訓練基礎模型

train_ddpm 函數：

  • 設定優化器 (AdamW) 和學習率排程器 (ReduceLROnPlateau)。
  • 訓練迴圈：
    • 模型設為訓練模式。
    • 從訓練 DataLoader 取批次數據 (條件序列 cond, 真實目標 target, 額外數據 extra_data)。
    • 隨機採樣時間步 t。
    • 計算損失 (diffusion.p_losses)。
    • 反向傳播並更新模型參數。
    • 梯度裁剪。
  • 驗證迴圈：
    • 模型設為評估模式。
    • 計算驗證集上的損失。
  • 學習率調整。
  • 早停 (Early Stopping)：若驗證損失在一定次數內未改善則停止訓練。
  • 儲存最佳模型和檢查點。
  • 繪製並儲存訓練/驗證損失曲線和學習率曲線。

筆記本中此階段主要用於載入已訓練好的基礎模型，而非從頭訓練。

階段四：誤差 DDPM 模型訓練準備

1. 定義誤差資料集相關函數

ErrorDataset 類別：

  • 儲存基礎模型預測產生的誤差數據。
  • 輸入：原始條件序列 (包含真實目標)、目標時間步的誤差、額外條件數據。
  • __getitem__ 返回模型輸入條件、目標誤差及額外數據。

filter_by_condition 函數：

根據指定的欄位和條件值篩選 DataFrame 中的數據。

generate_condition_errors 函數：

  • 使用訓練好的基礎模型 (diffusion)。
  • 針對篩選出的特定條件樣本 (如 condition_column='holiday', condition_value=1)。
  • 基礎模型對這些樣本進行預測 (diffusion.p_sample_loop)，得到正規化後的預測值。
  • 計算正規化空間中的誤差：真實目標 (正規化後) - 基礎模型預測 (正規化後)。
  • 收集原始條件序列、計算出的目標誤差和對應的額外數據。

create_error_dataset 函數：

整合 generate_condition_errors，篩選數據並創建 ErrorDataset 實例。

save_error_to_csv 函數：

將生成的目標誤差數據儲存為 CSV 檔案，方便後續分析或直接載入。

load_error_dataset 函數：

階段六：模型評估

1. 定義評估相關函數

calculate_metrics 函數：

計算 MSE, MAE, MAPE, SMAPE 等基礎評估指標。

compute_rgb_mean_std 函數：

計算資料集轉換為 RGB 熱力圖後的均值和標準差，用於 FID 計算中 Inception 模型的輸入正規化。

compute_fid 函數：

計算 Fréchet Inception Distance (FID)，衡量生成圖像與真實圖像分佈的相似性。

evaluate_model 函數： (更新後)

  • 評估單個模型（基礎或分層）的性能。
  • 接收確切的評估樣本數。
  • 若無預計算預測，則自行生成。
  • 計算基礎指標 (MSE, MAE, MAPE, SMAPE)。
  • 計算 FID：
    • 將網格數據轉換為 RGB 熱力圖。
    • 使用預訓練的 Inception V3 模型提取真實圖像和生成圖像的特徵。
    • 調用 compute_fid 計算 FID 值。
  • 計算並儲存每個網格點的平均誤差。
  • 繪製並儲存網格誤差圖 (plot_grid_with_error)。
  • 視覺化平均預測圖和單樣本預測圖 (visualize_predictions)。
  • 儲存匯總評估指標。

evaluate_hierarchical_model 函數：

  • 評估分層模型 (基礎模型 + 誤差模型) 在特定條件下的性能。
  • 篩選測試集中符合條件的樣本。
  • 基礎模型預測：使用 trained_diffusion。
  • 誤差模型預測：使用 trained_error_diffusion (輸入為原始條件)。
  • 分層模型預測 = 基礎預測 + 誤差預測。
  • 反正規化所有預測結果和真實目標。
  • 儲存基礎預測、計算出的誤差模型輸出 (原始尺度) 和真實值到 CSV。
  • 計算基礎模型和分層模型各自的指標 (MSE, MAE, MAPE, SMAPE)。
  • 計算分層模型的 FID (真實特徵可重用)。
  • 調用 evaluate_model 分別對基礎模型和分層模型的預計算結果進行詳細評估和視覺化。
  • 計算並儲存兩個模型指標之間的差異。

truncate_colormap 函數：

輔助函數，用於截斷 colormap 以獲得更好的視覺效果。

visualize_predictions 函數：

視覺化比較生成結果、真實數據以及誤差 (MSE, MAE, MAPE) 的圖形。

plot_grid_with_error 函數：

繪製網格圖，顯示每個網格點的誤差 (MSE, MAE, MAPE, SMAPE)，並儲存結果。

2. 執行評估

設定評估的樣本數和評估條件 (如 condition_column='holiday', condition_value=1)。

調用 evaluate_hierarchical_model 函數，傳入訓練好的基礎模型 (trained_diffusion)、誤差模型 (trained_error_diffusion) 和測試資料集。

輸出並記錄基礎模型和分層模型的各項評估指標。
