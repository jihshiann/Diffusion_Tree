DDPM 3D UNet 架構

人流預測模型結構的詳細視覺化

模型概述

DDPM 3D UNet 模型是為時空人流預測而設計的，實現了以 3D UNet 為骨幹的去噪擴散概率模型。該模型接收條件輸入序列，通過擴散過程生成未來的流量預測。

關鍵組件：

  • UNet3D：具有跳躍連接的神經網絡骨幹
  • DDPM3D：處理前向和反向擴散過程的擴散模型包裝器
  • DoubleConv3D：卷積操作的基本構建塊

DDPM3D 類別

主要的擴散模型包裝器，處理前向和反向擴散過程。

關鍵方法
  • q_sample：逐漸向輸入添加噪聲的前向擴散過程
  • p_losses：通過預測帶噪樣本中的噪聲來計算訓練損失
  • p_sample：反向擴散過程的單步操作
  • p_sample_loop：從噪聲生成樣本的完整反向擴散過程
  • get_time_embedding：為時間步創建位置嵌入
# 前向過程（逐漸添加噪聲）
def q_sample(self, x0, t, noise=None):
    if noise is None:
        noise = torch.randn_like(x0)
    sqrt_alpha = self.sqrt_alphas_cumprod[t].view(-1, 1, 1, 1, 1)
    sqrt_one_minus_alpha = self.sqrt_one_minus_alphas_cumprod[t].view(-1, 1, 1, 1, 1)
    return sqrt_alpha * x0 + sqrt_one_minus_alpha * noise

UNet3D 類別

具有編碼器-解碼器架構和跳躍連接的神經網絡骨幹。

組件
  • 編碼器塊（enc1-enc4）：下採樣並提取特徵
  • 瓶頸層：處理最壓縮的表示
  • 解碼器塊（dec1-dec4）：上採樣並通過跳躍連接組合特徵
  • 時間嵌入：處理時間步信息以調節網絡
  • 輸出卷積：將特徵轉換為最終輸出

輸入/輸出維度：

前向擴散

根據預定義的時間表逐漸向原始數據添加噪聲。對於時間步 t：

x_t = √αₜ * x₀ + √(1-αₜ) * ε

其中 ε 是隨機噪聲，αₜ 是噪聲調度的累積乘積。

模型訓練

UNet3D 模型被訓練以預測前向過程中添加的噪聲：

損失 = MSE(ε, ε_θ(x_t, t))

其中 ε_θ 是 UNet 模型預測的噪聲。

反向擴散

逐漸從隨機樣本中去除噪聲以生成數據：

x_{t-1} = 1/√αₜ * (x_t - β_t/√(1-α_t) * ε_θ(x_t, t)) + σ_t * z

其中 z 是隨機噪聲，σ_t 是步驟 t 的方差。

數據處理

該模型處理已轉換為網格格式的人流數據。輸入數據是 9 個時間步的序列，模型預測第 9 幀，同時以前 8 幀作為條件。

PeopleFlowDatasetCondition
  • 將 CSV 數據轉換為網格排列（21×21）
  • 標準化流量值
  • 創建輸入序列（condition_length + prediction_length）
  • 每個樣本返回：model_input (1, 9, 21, 21), target_seq (1, 1, 21, 21)

訓練與評估

該模型使用 AdamW 優化器和 MSE 損失進行訓練，並使用 MSE 和 MAE 指標進行評估。

關鍵參數：

  • 時間步數：1000（擴散過程步驟）
  • Beta 調度：從 1e-4 到 0.02 的線性變化
  • 學習率：0.0001
  • 基礎通道數：64（在 UNet 中）
  • 時間嵌入維度：128
