def get_time_embedding(self, t):
t = t.float()
emb = t[:, None] * self.freq_factor
return torch.cat([torch.sin(emb), torch.cos(emb)], dim=1)

資料處理

GridData - 處理CSV資料並構建網格
PeopleFlowDatasetPerCell - 每個單元格的時間序列資料
PeopleFlowDatasetForEval - 評估用的完整網格資料

訓練與評估

train_ddpm - 訓練每個單元格的擴散模型
evaluate_model_per_cell - 評估模型在測試集上的表現
評估指標: MSE, MAE, MAPE, SMAPE

主要參數

  • H, W = 21, 21 (網格大小)
  • condition_length = 8 (條件序列長度)
  • prediction_length = 1 (預測序列長度)
  • batch_size = 150
  • timesteps = 1000 (擴散步數)
  • lr = 0.0005 (學習率)
  • patience = 5 (早停耐心值)
